# CIVI radio icons

23 complete 32x32 RGB PNG icons, one per VI, without outer whitespace. Dark navy display with white text, #EC1E48 bottom display line, MON Morse code (-- --- -.) at the top, three black/dark-gray buttons, and a silver-rimmed dark-gray tuning knob with a black finger recess. No direction pointer. Regenerate this edition with ../make_color_set.py.

READ and SET distinguish the APIs. EX marks examples, OLD marks legacy read VIs, and EX-OLD marks the legacy read example. See manifest.csv.

These PNGs include all text. Clear existing icon text, templates and user artwork before importing to avoid overlapping the new icon. This package does not modify the VI files. preview.png is an enlarged contact sheet, not an importable VI icon.

Regenerate using ../make_color_set.py (Python standard library only).
