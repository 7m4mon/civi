# 構成と運用上の制限

`server.py`はSCPI TCPとHTTPSの入り口、`scpi.py`は解析、`service.py`は共通制御キュー、`backend.py`は模擬/直接CI-V、`network.py`はOSのNIC情報とzeroconfです。Web静的ファイルはすべて同梱しCDNは使いません。Web認証はHTTPS上のBasic認証、操作APIは専用ヘッダーとOrigin照合でクロスサイト操作を拒否します。Webの詳細状態APIとログも認証対象です。認証不要の`/health`はgateway/radio/readyのみを返し、設定・機器識別情報・ログを返しません。ログイン前から準備待ち画面を表示するために使用します。

サービスの単一workerだけがバックエンドを呼びます。同期シリアルI/Oはスレッドへ移し、イベントループではWebハートビート、TCP入力、切断を監視します。通常操作は投入順に処理し、1つのSCPI行内の設定と問い合わせを他クライアントと混ぜません。安全停止は優先キューを使い、長い複合行とポーリングの各操作境界でも停止期限を確認します。

CI-Vフレームは分割/連結/エコー/余分なプリアンブルを処理し、応答のアドレスとコマンドを照合します。00/01のブロードキャストは取引応答から分離してバックエンドの履歴に保持し、Web表示は約2秒間隔の問い合わせで更新します。ACK/NAKには対象コマンド情報がないため、専有アクセスと未解決取引の隔離が必要です。

## 接続障害

状態は`disconnected`、`connected`、`quarantined`。ポートオープン前の不在は約2秒間隔のポーリングで再試行します。送出後のI/O障害、タイムアウト、不正な応答は隔離し、通常操作を拒否します。Webキャッシュは無効にし、以前の測定値を現時点の値として表示しません。

CI-Vには取引IDがないため、単なる待機時間では任意に遅れた同一コマンド応答を識別できません。隔離後は無線機を受信状態へ戻し、無線機とUSBリンクをリセットして未処理応答を除去し、Webの確認チェックと「復旧」を使用してください。復旧時に周波数とPTT状態を問い合わせます。USBの差し直しやCOM設定変更だけでは隔離を解除しません。物理的リセットが実際に行われたことをソフトウェアは証明できません。

同じCI-Vバスを別の制御ソフトが使用する運用は対象外です。受信元・宛先が同じ他コントローラーのACKは区別できません。シリアルポートはCIVIだけが使用してください。

## 送信制御

`transmit.enabled = false`が既定。明示的に有効化するとSCPIとWebのPTT ONを許可します。送信開始を試みる前に所有クライアントと開始時刻を記録し、開始ACKが失われても停止対象として追跡します。他クライアントのONを拒否しますが、OFFはどの操作クライアントからも受理します。ONを繰り返しても同じ送信の期限は延びません。

最大送信時間は`max_seconds`。監視間隔は0.25秒、実行中のCI-V操作を途中破棄しないため、停止試行開始は最大で現在のシリアルタイムアウト分遅れることがあります。リアルタイム制御ではありません。Webは2秒ごとのハートビートで接続を更新し、既定10秒のリース失効時に停止を試みます。TCPはEOF/通信エラーで停止を試みます。ケーブル断や通信不能でTCPの切断が即時検知できない場合も最大送信時間は適用されます。

時間超過、クライアント切断、通常終了時にOFFを送ります。隔離中もOFF送出は試みますが、遅延ACKとの識別ができないため停止成功とは報告しません。失敗時は所有状態を残し、再試行とログ記録を続けます。物理的に受信状態とリンクリセットを確認して復旧してください。

USB切断中、無線機の異常、プロセス強制終了、PC停止時には停止を保証できません。無線機側のタイムアウト機構と実機での安全確認が必要です。CIVIが開始していない送信を自動監視で停止することはありません。自動テストは実機へPTT ONを送信しません。

CI-V接続設定は認証済みWebから起動中に変更できます。変更は同じキュー内でポートを閉じて適用し、送信の停止が未確認なら拒否します。永続化はconfig.tomlの編集で行います。送信有効化・最大時間・パスワードの変更は設定/環境変数を変更し再起動します。

mDNSはzeroconfで独自`_scpi-raw._tcp`と`_https._tcp`を広告します。`_lxi._tcp`は広告しません。マルチNICでは各IPv4を表示/広告しますが、LXI用のNIC選択・名前衝突の永続化・リンク変更追従は未実装です。LAN設定変更はOS側で行います。
