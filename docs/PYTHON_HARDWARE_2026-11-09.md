# Pythonクライアント0.12.1 実機スモーク試験 — 2026-11-09

ユーザーが電源投入済みのIC-7300へ、PiのCIVIを経由して限定的に接続・操作しました。
接続先は`TCPIP::192.168.73.2::5025::SOCKET`、CIVIゲートウェイ版0.1.0。
Windowsの別venvへ導入したクライアント0.12.1を使用し、状態照会はON。
初期状態をローカルJSONへ保存してから変更し、各操作のfinallyで元値へ戻しました。

## 変更・読戻し・復元

| 項目 | 初期値 | 変更後の実値 | 復元後の実値 | 結果 |
|---|---|---|---|---|
| 周波数 | 774000 Hz | 775000 Hz（表示/選択VFOとも一致） | 774000 Hz | 成功 |
| 選択VFOモード | AM / DATA OFF / FIL2 | USB / DATA OFF / FIL2（表示もUSB） | AM / DATA OFF / FIL2 | 成功 |

設定命令は送信前の許可リストで制限し、次の4命令だけを送りました。

```text
SENS:FREQ 775000
SENS:FREQ 774000
RAD:VFO:MODE SELECTED,010002
RAD:VFO:MODE SELECTED,020002
```

これらに処理完了/状態照会と読戻しの問い合わせが伴います。
周波数とモードだけでなく、最終の表示値・両VFO周波数/モード/DATA/フィルター・
PTT/VOX/BK-IN/tunerのスナップショット全体が初期値と一致しました。

## 読取りだけを確認した項目

- GatewayIdentification: CIVI Project / CIVI/IC-7300、ゲートウェイ版0.1.0。
- 手動ファームウェア情報: Unknown。無線機版を自動取得したものではありません。
- Sメーター: 試験スナップショットではraw 25→20。受信値なので同値復帰を要求しません。
- 新しい階層`band_stacks[3].slots[1]`: 7050000 Hz / LSB / FIL2 / DATA OFF。
- スコープSTREAM/ENABLE: いずれもOFF。開始せず、試験後もOFFのまま。
- 明示的な処理完了待ち: 成功。
