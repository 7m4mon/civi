# DHCP / AutoIP acceptance — 2026-11-08

This is a Pi network-stack acceptance test, not an LXI conformance declaration. It exercises the existing CIVI automatic IPv4 implementation; no production radio, Web password or host interface is reconfigured.

## Environment and method

Raspberry Pi 4, Debian 13.7/aarch64, Python 3.13.5 and NetworkManager 1.52.1. A private NetworkManager and private D-Bus run in isolated network/mount/UTS namespaces. Two veth endpoints connect only the private client and a dnsmasq DHCP server. The test uses documentation addresses `192.0.2.0/24` and synthetic MAC `02:c1:71:00:00:02`.

The client runs CIVI's actual `NetworkManager`, `Transactions` and `Checkpoints` classes to apply and confirm automatic IPv4. A raw socket records DHCP exchanges to PCAP and JSONL. Production eth0/WLAN, NetworkManager, Avahi, Ping settings and CIVI processes remain outside the experiment.

## Observations

| Check | Result |
|---|---|
| Start without DHCP | Link-local `169.254.* /16` address assigned |
| Server becomes available | Client obtains `192.0.2.10/24`, gateway `.1`, DNS `.53` |
| DHCP request parameters | Packet capture includes requested subnet mask, router and DNS options 1/3/6 |
| Natural renewal | A REQUEST with the existing address in `ciaddr` receives an ACK; gateway changes to `.254`, DNS to `.54` without forced client reactivation |
| Lease expiry | With the server stopped, the 120-second lease expires; DHCP address and gateway disappear |
| Fallback | Client has a `169.254.* /16` address after expiry |
| Server returns | Client reacquires `192.0.2.10/24` with the new gateway and DNS |

The first recorded lease and renewal ACKs were 60 seconds apart. Expiry was observed 120 seconds after the renewal ACK. These are observations of this short test lease, not timing guarantees for other DHCP servers.

## Reproduce

Run manually from the Pi checkout, with `ip`, `unshare`, `nsenter`, `dbus-daemon`, NetworkManager and `dnsmasq` installed:

```bash
cd ~/civi-rpi-lxi
sudo python3 tools/pi_dhcp_check.py
```

The script prints progress and leaves root-only artifacts below ignored `tmp/dhcp-lab-*`: `steps.log`, `baseline.json`, `results.json`, `cleanup.json`, `traffic.pcap`, `packets.jsonl` and daemon logs. It checks that the real wired profile/IPv4, NetworkManager PID and resolver-file hash match their pre-test baseline, and removes only its own namespaces. It is not part of ordinary pytest and requires no CIVI restart.

The first run completed the DHCP checks but reported a cleanup race while descendant processes were exiting. The remaining empty test namespace was removed after inspection. The script now handles termination in its private daemon wrapper and waits for descendants before deleting namespaces. The complete repeat passed, including namespace removal and `host_network_unchanged: true` at 08:47:31 Pi local time.

The successful run's artifacts are at `/home/nom/civi-rpi-lxi/tmp/dhcp-lab-20261108-084402-4a26ff`. Its natural renewal occurred at 08:45:22, expiry at 08:47:22 and reacquisition by 08:47:30. The real wired address remained `192.168.73.2/24`.

After the [duplicate-IP test](RPI_CONFLICT.md) exposed Debian Netplan importing host profiles into the fixture, isolation was extended to all of `/run` and Netplan's inputs. A complete DHCP repeat with that corrected fixture passed: natural renewal at 09:08:44, expiry at 09:10:44 and DHCP return by 09:10:52 Pi local time. The earlier run alone is not used to establish complete fixture isolation.

## Limits and remaining work

- This verifies the Pi's real NetworkManager with CIVI's configuration through a virtual Ethernet link. Physical eth0, cable disconnection and boot retention are separate tests.
- DNS server values are checked in DHCP packets and active NetworkManager state. Successful system-resolver queries and external routing are not asserted.
- AutoIP allocation is checked; peer-to-peer AutoIP traffic and the full RFC 3927 conflict/timing behavior are not covered.
- Duplicate IPv4 addresses, real hostname collisions, unusual DHCP options, server rejection and every LXI DHCP recommendation remain outside this run.
- Automated Windows regression: **259 passed, 1 skipped**. The skip is the Linux-only Unix-socket integration; it is not counted as a pass.
