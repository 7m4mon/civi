# Pythonクライアント0.11.0 バンドスタック階層 — 2026-11-09

バンド→保存枠の階層を追加しました。

```python
slot = device.band_stacks[3].slots[1]
value = slot.settings
```

正規のバンド集合は`device.band_stacks.bands`で、11バンドを整数番号で列挙します。
各バンドのslotsには3枠があります。従来の`band_stacks[3, 1]`は同じ操作オブジェクトを返し、
旧APIの件数33・(band, slot)の列挙も維持します。
件数/列挙を不意に変更せず、階層に沿った列挙はbandsから行う設計です。

バンド/枠の番号・nameと子への参照は読取専用で、nameは各階層の物理識別子の数字文字列。
MHz等の推測ラベルは付けません。参照取得や番号検証では無線機I/Oを行いません。
参照はセッション内で共有しますが、設定値はキャッシュせず、その都度読み取ります。
操作は既存のmemory権限、状態照会方針、同一セッションの排他処理を共有します。
[型・使用例・互換性](../drivers/civi-ic7300/src/civi_ic7300/HIERARCHY.md)を配布物へ同梱しました。
