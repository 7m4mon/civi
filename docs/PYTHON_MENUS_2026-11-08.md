# Pythonクライアント0.4.0 メニューAPI — 2026-11-08

**216メニューの型付きAPIを実装**。すべて読取可能で、215項目は書込可能。
0074は従来どおり読取専用、0028は予約番号で受け付けない。
Pi・実無線機を操作せず、Windows＋模擬バックエンドで実装/検証した。
IVI適合/登録済みとは表示しない。

## 操作と型

`driver.menus[2].value`、または`driver.menus.integer_item("0002").value`で利用する。
`write_and_read(value)`は設定、エラー確認、実値の読み戻しを行う。
`definition`から型、範囲/刻み/単位、選択肢、書込方向と必要な権限区分を読める。
[216項目の一覧](../drivers/civi-ic7300/src/civi_ic7300/MENUS.md)を同梱した。

| 種類 | Python値 |
|---|---|
| ON/OFF | bool |
| 整数/列挙コード/リピーターoffset | int。項目別の範囲/選択肢/刻み。offsetはHz、1000 Hz刻み |
| 音声HPF/LPF | AudioFilter。HPF/LPFのインデックスコード |
| TX帯域 | Bandwidth。2つの0..3コード |
| 色 | RgbColor。RGB各0..255 |
| 保存済みスコープエッジ | ScopeEdges。Hz、whole kHz、順序付き |
| 起動画面文字列 | str。許可されたASCII最大10文字 |
| 日付/時刻 | datetime.date / datetime.time。2000..2099年、時刻はHH:MM |
| UTC差 | datetime.timedelta。±14時間、whole minute |

型付きアクセサーは異なる種類の項目を拒否する。未定義番号・型/範囲違反・命令の埋込みは
I/O前に拒否し、不正な機器応答はProtocolError。メニューの表示名は既存ゲートウェイ
カタログに従い、説明がない列挙コードに推測のラベルや物理単位を付けない。

## 書込権限とエラー

実接続では既存のCIVI `[permissions]` に従い、menu / link / calibrationを分離する。
クライアントから実ゲートウェイの権限を有効化するAPIは追加していない。
メニュー書込は自動状態照会がOFFでも、事前エラーを確認してから送信し、結果を確認する。
権限拒否、NAK、シリアル失敗はDeviceErrorとなり、失敗後の読み戻しは実行しない。
実値が丸められた場合は、要求値へ偽装せず実際の読み戻し値を返す。

模擬動作も3区分すべて初期OFF。
`menus.set_simulated_write_permissions(menu=True)`で模擬の通常メニューだけを許可できる。
実TCP接続でこのメソッドを呼ぶとRuntimeErrorになり、実権限は変わらない。
時計は値の保存のみ、USB/送信/リンク設定の副作用や接続切断は模擬しない。
receive resetはメニューを一括初期化しないが、0081/backlightのような通常操作との別名は
同じ状態を表す。backlightをリセットすれば、そのメニューの読値も変わる。

## 検証結果

- クライアント全体 **59成功**。216読取＋215変更/読戻し/元値復元を両模擬系で確認。
- 通常/リンク/校正の既定拒否と独立許可、0074書込拒否、215項目の型/範囲変換を検証。
- HPF、帯域、RGB、signed offset、保存エッジ、文字列、日付、時刻、UTC差、bool/intの
  独立CI-Vベクトルを確認。例: RGB(1,128,255)=`000101280255`、UTC -05:30=`053001`。
- NAK/タイムアウト/事前エラー、丸め、末尾空白正規化、同一クライアントの並行write/readを確認。
- mypy 2.4.1 `--strict`: **7ソース、エラー0**。
- Windows全体試験 **344成功・1スキップ（28.74秒）**。Linux専用パネル試験は以前Piで成功済み。

通信設定・校正を含む書込試験は模擬のみで、実IC-7300の全項目/モード/値の検証ではない。
数値の範囲内でも機種/ファーム/運用モードによって実機が拒否する場合はエラーとして扱う。

## 配布と残件

メニュー定義は開発時に`tools/python_driver_menu_catalog.py`でCIVIからJSONへ書き出す。
配布パッケージはそのJSONを持ち、CIVI本体をimportしない。
`--check`と試験で元カタログとの差異を確認する。
APIと方向別対応表は`tools/python_driver_docs.py`で再生成する。

拡張339定義中、**288が全方向対応、2が部分対応、49が未対応**。
[全コマンドの対応表](PYTHON_DRIVER_COVERAGE.md)。メモリー・バンドスタック・キーヤー等の
複合データ、送信/電源などの残りの適用対象APIと、最終要件照合/命名/文書/登録が残る。
