# Pythonクライアント0.12.0 基本コマンド・別名監査 — 2026-11-09

[統合対応表](PYTHON_SCPI_AUDIT.md)に、拡張339＋基本/専用11系統の**350ヘッダー**を整理。
読書き方向、専用API、内部利用、短縮/全形の別名、対象外形式と理由を一つの資料へまとめました。
別名の綴りを機能数として水増しせず、対応していない読書き方向も対応済みとは数えません。
ソフトウェア上のゲートウェイ対応表であり、全無線機機能やIVI適合の証明ではありません。

## 補ったAPI

- `ivi_utility.identification`でIDNの4項目を不変なGatewayIdentificationとして取得。
  serial_numberはCIVIの識別番号、software_revisionはCIVI版で、無線機版とは区別。
- `clear_status()`でこのクライアントのエラーだけをクリア。隔離解除や機器resetは行わない。
- `wait_for_complete()`で*OPC?を明示呼出し。完了と先行設定の成功は区別し、状態照会設定に従う。
- `radio.firmware_revision`で手動登録値またはUnknownを取得。CI-V自動読取とは表示しない。
- `operations.start_transmit()` / `stop_transmit()`で明示的なPTT開始/停止。
  既存の送信許可・所有権・最大時間に従い、OFFはCIVI所有のCW/音声/VOX等も停止を試みる。
  読取専用のradio.transmittingは維持する。

`*RST`、非問い合わせの`*OPC`、状態レジスター/SRQ、self-test、`*WAI`などはゲートウェイが
提供しない形式として記録し、実際に拒否されることを確認。
reset()はCIVIの受信基準状態への操作であり、`*RST`やIcomのPartial/All Resetと同一視しません。
[配布物の基本API説明](../drivers/civi-ic7300/src/civi_ic7300/BASIC.md)へ意味と制約を記載しました。
