# Pythonクライアント0.6.0 スキャン・トーン — 2026-11-09

スキャン21定義、リピーター/トーンスケルチ周波数2定義、スコープの部分対応だった
2定義の書込方向を追加しました。拡張339定義中 **321全方向対応・部分0・未対応18**。
[対応表](PYTHON_DRIVER_COVERAGE.md)はAPI実装一覧で、実機検証/IVI適合の証拠ではありません。
今回もWindowsの模擬環境だけで検証し、Pi・実無線機を操作していません。

## API

`device.scan`に開始/停止、Δスキャン幅、選択スキャン有効化、再開設定、
選択中メモリーへのグループ割当、走査グループ選択を追加。
スキャンは問合せがないため、成功は命令受理まで。走査完了・現在の走査状態や
以前の設定への復元を推測で表示する機能はありません。模擬試験の最後には停止命令を送りました。
入力をI/O前に検証し、自動状態照会がOFFでも操作前後のエラーを確認します。
グループ割当は既存ゲートウェイどおりmemory権限ゲートのない命令で、
無線機の現在選択に作用します。複数クライアント間の排他は保証しません。

`radio.repeater_tone_hz` / `radio.tone_squelch_hz`は67.0..254.1 Hz、0.1 Hz刻み。
トーンのON/OFFとは別設定で、実機が全ての数値を受理するとは限りません。
スカラープロパティは既存の自動状態照会オプションに従います。
`scope.display_code` / `dual_scope_code`の書込は整数0だけを受け付け、
スコープの機能自体を増やすものではありません。
[API詳細と模擬例](../drivers/civi-ic7300/src/civi_ic7300/SCAN.md)を同梱。

## 検証結果

- 新規16成功、クライアント全体101成功。
- 全体 **386成功・Linux専用1スキップ（29.73秒）**。
- スキャン21定義を両模擬系で操作。実TCPハンドラー＋MockBackendでCI-Vの固定バイト列、
  パラメーター付きグループ命令を独立した期待値と照合。
- トーンは境界/中間値を設定・読戻し・元値復元。要求の2バイトBCDと応答の先頭0付き
  3バイトBCDを区別。スコープは唯一許される0の書込/読戻しと1の拒否を確認。
- NAK、シリアルtimeoutエラー注入、事前エラーの中断、命令埋込み/型/範囲違反、
  不正なトーン応答、複数スレッドでの操作とメーター問合せの混線防止を確認。
  物理シリアルtimeout試験ではありません。
- strict型検査: 10ソース、エラー0。
- sdist/wheel作成と別venvへのオフライン導入、isolated modeでの動作/同梱説明、
  ゲートウェイ非依存を確認。導入した型情報で正常例を受理し、誤用3件を検出。

模擬環境はスキャン中の周波数移動、受信信号探索、再開の時間変化やグループ割当による
保存レコード変更を再現しません。実機動作、モード別の制限、保存の永続性は未確認です。
IVI適合/登録は未達で、残る18定義と仕様全体の照合を続けます。
