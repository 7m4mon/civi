# LXI対応表（計画・未認証）

対象は[LXI Device Specification 1.6.2公式PDF](https://public.lxistandard.org/specifications/LXI_1.6_Specifications/LXI_Device_Specification_1.6.2_2026-04-02.pdf)。PDF表紙の日付は2026-04-04、ファイル名の日付は2026-04-02です。以下は対象領域を整理した設計用対応表で、全条項を網羅する認証チェックリストではありません。必須/推奨/任意は該当条項のRULE/Recommendation/Permission、またはExtended Functionの区分に対応します。

初期版はSCPIネットワークゲートウェイです。実装がある項目もLXIの適合試験は未実施です。LXIロゴや認証済み表示を使用せず、Welcome画面に未認証を表示します。

2026-10-29にWindows/Linux共通機能の一部を実装しました。[使用方法・検証範囲・制限](LXI_IMPLEMENTATION.md)を参照してください。以下の「実装」は条項全体の適合を意味しません。

HTTPSとパスワードだけでセキュリティ適合を主張しません。LXI API関連、証明書管理、規格に必要なセキュリティ機能の詳細マッピングは移植/LXI対応段階で追加します。予約された`/lxi`配下に独自APIを置かず、CIVIのAPIは`/api`に分離しています。

未実装項目は上表の未対応部分、GPIO/物理表示、OSのLAN設定・LCI、識別APIの残要件、mDNSホスト名処理・競合名保存、IVIドライバー/登録、規格セキュリティ、全適合試験です。公式認証を取得するまでは認証済みと表示せず、未実装の必須要件がある間は適合も主張しません。
