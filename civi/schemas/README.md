# Identification schema

`InstrumentIdentification-2.0.xsd` is the unmodified LXI Consortium identification
schema downloaded from:

https://public.lxistandard.org/schemas/InstrumentIdentification/2.0

Retrieved 2026-10-29. Its internal revision header is March 10, 2025.
The explanatory schema page is:
https://public.lxistandard.org/schemas/InstrumentIdentification/2.0.html

CIVI serves this schema locally at `/InstrumentIdentification/2.0` so XML clients
do not need Internet access. Schema validation does not establish LXI conformance.
