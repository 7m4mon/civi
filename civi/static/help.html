CIVI local documentation

Radio control · Welcome · LAN information / discovery

SCPI / VISA

Use the Instrument Address String on the Welcome page as a VISA RAW SOCKET resource. Use ASCII commands terminated by LF. Set commands have no normal response; queries return LF-terminated lines. Multiple query responses in one command line are separated by semicolons. Quoted error messages may also contain semicolons.

*IDN?
SENS:FREQ?
RAD:MODE?
READ:SMET?
RAD:PTT?
SENS:FREQ 7.1MHz
*OPC?
SYST:ERR?

OPC confirms completion. Always check SYST:ERR? to determine success. S-meter values are uncalibrated raw 0–255; no dBm conversion is made.

Scope

IC-7300 USB CI-V must use 115200 baud and be unlinked from [REMOTE]. Use Start scope on the radio control page, or RAD:SCOPE:STREAM 0,ON followed by RAD:SCOPE:ENABLE 0,ON. Wait for a complete sweep before RAD:SCOPE:WAVE?. Levels are uncalibrated.

Receive reset

RAD:RESET;SYST:ERR? restores the operating profile captured after the user's Partial Reset: PTT/CW/voice/VOX/BK-IN/tuner off, scan stopped, both VFOs at 14.100 MHz USB/DATA OFF/FIL2 and 57 operating/scope settings. It selects VFO A and verifies readback. It is not a full Icom Partial/All Reset or LAN RESET. Memories, menus, calibration, stored scope edges and network settings are unchanged. A failure can leave a partially applied state; no automatic rollback is performed.

Connections and safety

Web operations require administrator authentication. The SCPI port has no authentication; restrict access to the intended LAN. Transmit control is disabled by default. A USB disconnect prevents guaranteed TX stop.

A CI-V timeout quarantines the radio link. Restore the radio to RX and reset its USB link before using Recover connection.

LXI implementation status

CIVI provides identification XML, a Welcome page and discovery services as part of ongoing LXI work. Empty or whitespace-only Description saves restore CIVI followed by the device serial number; an empty Pi hostname restores civi. These are factory-name resets, separate from LAN RESET retaining the last user-configured names. It does not claim LXI conformance, certification or extended functions. The optional Pi LAN helper supports temporary wired IPv4 changes, confirmation and rollback. Pi discovery uses Avahi for hostname/service collision handling; desired and acquired names are saved separately. The advertised mDNS name can have a numeric suffix. On Pi, disabling discovery stops Avahi hostname replies and service advertisements, blocks reactivation and persists across boot. Use the numeric IP address to reopen the network page and enable discovery again. Other Avahi applications are affected too. LAN RESET re-enables Avahi. Windows only withdraws CIVI services. Pi hostname saving and local LAN RESET are available; physical indicators, IVI drivers and full validation remain incomplete. Discovery settings do not change the host OS network adapter configuration. CIVI is started manually; no automatic startup is installed.

Pi local LAN RESET

The Pi network page provides authenticated IPv4 Ping reply controls. Read the current setting, then enable/disable and save it. This affects all Pi interfaces, persists through OS sysctl settings and leaves HTTPS/SCPI available. IPv6 is unchanged. LAN RESET enables IPv4 replies again.

Local LAN / Identify panel

Start bash panel.sh in another Pi desktop terminal and keep the attached display visible. On the Welcome or network page, enter the current Web password and use Start Identify / Stop Identify. The local banner flashes green until stopped. The panel shows wired IP and faults; connector LEDs are left alone. A hidden/offline display is reported, and starting without a visible local panel is rejected. F11 toggles fullscreen; Esc leaves fullscreen.

If you forgot only the Web password, use bash password-reset.sh from the Pi attached keyboard/display as the normal CIVI user. Type PASSWORD RESET and enter a new password twice. The old password is not required, and LAN/IP settings are retained. Updated running CIVI reloads it within about five seconds.

To change the current Web password, open Change Web password. Enter the current password and a new 12–256 character password twice. The change is immediate and persists across manual restarts. LAN RESET restores the device recovery default.

With the updated LAN helper running, open a terminal using the Pi attached keyboard/display, enter the CIVI directory and run bash lan-reset.sh as the normal CIVI user. Read the scope and type LAN RESET to confirm. SSH and redirected input are refused.

This saves DHCP with AutoIP fallback, clears manual wired IPv4/gateway/DNS, enables IPv4 Ping replies and CIVI discovery, and resets the Web password to the device recovery default displayed locally. The fixed wired IP will be lost. There is no 90-second reversion after a successful local reset. WLAN profiles, hostname and service description are retained. A connected Ethernet interface with one active NetworkManager profile is required.

Updated running CIVI reloads the new password and discovery settings; a stopped CIVI uses them on its next manual launch. The recovery password overrides the password environment variable. This reset does not alter firewall rules or auto-negotiation. No radio command is sent by the reset.
